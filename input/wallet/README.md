# Cartella File Esportati da App Spese (Wallet, Monefy, Spendee, ecc.)

Inserisci qui dentro (oppure in `input/bank_statements/`) le esportazioni CSV della tua app di tracciamento spese (es. **Wallet by BudgetBakers**).

### Formato Supportato
- CSV con separatore `;` o `,`
- Colonne tipiche: `account`, `category`, `currency`, `amount`, `ref_currency_amount`, `type`, `payment_type`, `date`, `note`
- LORIS riconosce automaticamente sia le spese elettroniche sia quelle in **contanti (CASH)**!
- **Garanzia Privacy & Saldi**: I dati di Wallet arricchiscono le statistiche e le categorie senza alterare il saldo patrimoniale reale dei tuoi conti bancari ufficiali.
