======================================================================
  🐾 GUIDA COMPLETA A LORIS — Local Overview of Resources, Investments & Spending
======================================================================

LORIS è un sistema di finanza personale offline, privato e riservato al 100%.
Non richiede registrazione, non invia alcun dato a server esterni e garantisce
privacy assoluta. Funziona direttamente elaborando i tuoi estratti conto bancari.

======================================================================
1. COME ESPORTARE GLI ESTRATTI CONTO DALLE TUE BANCHE & APP
======================================================================

Per ottenere i dati da dare a LORIS, esporta i file ufficiali dalle tue banche:

• 📱 REVOLUT:
  1. Apri l'app Revolut sullo smartphone (o dal browser su revolut.com).
  2. Dalla schermata Home, tocca i tre puntini "..." accanto al saldo oppure "Estratti conto" / "Statement".
  3. Seleziona il tipo di documento: "Estratto conto" (Account Statement).
  4. Scegli il formato: Consigliato CSV (oppure PDF).
  5. Scegli l'intervallo temporale (es. "Tutto il periodo", "Ultimi 12 mesi", o un mese specifico).
  6. Tocca "Genera" / "Esporta" e invia il file al computer (AirDrop, email, salvataggio file).

• 📱 TRADE REPUBLIC:
  - Metodo A (PDF ufficiale mensile/trimestrale):
    1. Apri l'app Trade Republic -> Profilo (in basso a destra o iniziale in alto a sinistra).
    2. Vai nella sezione "Documenti" / "Attività".
    3. Cerca i documenti nominati "Estratto conto" / "Account Statement" / "Kontoauszug".
    4. Scarica il file PDF.
  - Metodo B (CSV transazioni da portale Web o App):
    1. Accedi da computer a traderepublic.com (o da app).
    2. Nella sezione saldo / transazioni, clicca su "Esporta transazioni" / "Download CSV".
    3. Scarica il file CSV. LORIS riconosce entrambi i formati!

• 📱 WALLET APP (BudgetBakers - Spese & Contanti Cash):
  1. Apri l'app Wallet sul telefono o su web.budgetbakers.com.
  2. Vai su Impostazioni -> "Esporta dati" (Export data).
  3. Seleziona il formato "CSV" e l'intervallo di date desiderato.
  4. Scarica il file CSV. Utile soprattutto per tracciare pagamenti in contanti (CASH).

• 🏛️ ALTRE BANCHE ITALIANE ED EUROPEE (Intesa Sanpaolo, UniCredit, Fineco, N26, Widiba, Sparkasse, Poste Italiane, ecc.):
  1. Accedi all'Home Banking dal sito web della banca da computer.
  2. Vai nella sezione "Movimenti" o "Estratto Conto e Documenti".
  3. Cerca il pulsante "Esporta" / "Scarica movimenti" e scegli formato CSV, Excel (.xlsx/.xls) o PDF.
  4. Salva il file sul tuo computer.

2. COME INSTALLARE E AVVIARE LORIS
======================================================================

• 🍏 SU MAC (macOS):
  1. Estrai la cartella LORIS (se hai scaricato il file .zip).
  2. Fai semplicemente DOPPIO CLIC sul file:
     👉 start.command
  3. Se macOS mostra l'avviso "Impossibile aprire perché proviene da uno sviluppatore non identificato":
     - Fai TASTO DESTRO (o Control + Clic) su `start.command` -> seleziona "Apri" -> clicca "Apri".
     - Questa conferma è richiesta solo la prima volta.
  4. Lo script configurerà automaticamente l'ambiente Python e aprirà la dashboard nel tuo browser!

  Metodo alternativo da Terminale:
  Apri il Terminale nella cartella ed esegui:
     ./run_app.sh

  Per generare l'applicazione nativa per macOS con icona nel Dock:
     ./run_app.sh macos-app

• 🪟 SU WINDOWS:
  1. Assicurati di avere Python 3.10 o successivo installato (scaricalo da https://www.python.org/downloads/
     ricordandoti di spuntare la casella "Add Python to PATH" durante l'installazione).
  2. Estrai la cartella LORIS.
  3. Fai semplicemente DOPPIO CLIC sul file:
     👉 start.bat
  4. Lo script installerà le dipendenze in locale e aprirà automaticamente http://localhost:8502 nel browser.

• 🐧 SU LINUX:
  Apri il terminale nella cartella ed esegui:
     chmod +x run_app.sh
     ./run_app.sh

3. COME CARICARE I FILE IN LORIS
======================================================================

Una volta avviata l'app:
A) TRAMITE TRASCINAMENTO (Drag & Drop nell'interfaccia - Consigliato):
   - Nella barra laterale sinistra trovi il riquadro "Carica Estratti Conto (PDF, CSV, Excel)".
   - Trascina uno o più file direttamente nel riquadro.
   - LORIS riconosce istantaneamente la banca, pulisce le transazioni, riconcilia
     i giroconti interni ed aggiorna saldi e grafici.

B) TRAMITE CARTELLA DEL COMPUTER:
   - Copia i file degli estratti conto in:
     `input/bank_statements/`
   - Se hai un file con i tuoi investimenti / titoli azionari / ETF:
     `input/investments/`
   - Se hai il CSV esportato da Wallet (BudgetBakers):
     `input/wallet/`
   - Nella dashboard clicca su "Ricarica Dati".

4. MODIFICHE MANUALI & FUNZIONE UNDO (MASSIMO CONTROLLO)
======================================================================

• ↩️ ANNULLA ULTIMO CARICAMENTO (Undo):
  Se carichi per errore un file non corretto o duplicato, nella barra laterale sinistra
  compare il pulsante "↩️ Annulla Ultimo Caricamento": con un clic ripristini la situazione precedente.

• 🗑️ ELIMINA FILE SINGOLI:
  Sempre nella barra laterale, sotto la lista dei file caricati, c'è un'icona 🗑️ accanto ad ogni file
  per rimuoverlo singolarmente da disco.

• ✏️ MODIFICA MANUALE SALDI DEI CONTI:
  Nella scheda "🏦 Patrimonio & Saldi", apri il riquadro a scomparsa "✏️ Modifica Manuale Saldi dei Conti":
  puoi verificare il saldo rilevato da LORIS e sovrascriverlo con il saldo esatto a tua scelta.

• ✏️ MODIFICA CATEGORIE & TRANSAZIONI:
  Nella scheda "📑 Estratti Conto & Transazioni", apri "✏️ Modifica Transazioni & Categorie":
  puoi cambiare la categoria di qualunque spesa, escludere un movimento o contrassegnarlo come giroconto.

• ➕ AGGIUNGI MOVIMENTO MANUALE:
  Puoi aggiungere a mano qualsiasi spesa o entrata non presente nell'estratto conto.

5. COME CONDIVIDERE O ESPORTARE LORIS AD ALTRE PERSONE
======================================================================

Se vuoi passare LORIS ad un amico o su un altro computer in totale sicurezza:

1. VIA GITHUB (Consigliato per ricevere aggiornamenti automatici):
   Condividi il link del repository pubblico:
   👉 https://github.com/fabianimarco98/LORIS-Local-Overview-of-Resources-Investments-Spending

   Il tuo amico può scaricare lo ZIP cliccando su "Code" -> "Download ZIP" oppure clonare con:
   git clone https://github.com/fabianimarco98/LORIS-Local-Overview-of-Resources-Investments-Spending.git

2. VIA PACCHETTO ZIP CONDIVISIBILE PULITO:
   Dalla cartella del progetto, esegui da terminale:
   ./run_app.sh package
   Verrà generato il file:
   👉 LORIS_Condividi.zip
   Questo archivio esclude automaticamente il 100% dei tuoi estratti conto personali,
   i file PDF/CSV privati, i log e i file temporanei. Puoi mandarlo via Telegram,
   AirDrop o Google Drive in tutta serenità!

6. CHAT AI LOCALE CON OLLAMA (OPZIONALE)
======================================================================

LORIS dispone già di un potente motore di regole offline. Se desideri anche chattare
in linguaggio naturale con i tuoi dati:
1. Installa Ollama da https://ollama.com (oppure via Homebrew con `brew install ollama`).
2. Scarica un modello rapido e leggero da terminale:
   ollama run llama3.2
3. LORIS si collegherà automaticamente in locale (porta 11434). Nessun dato lascia il tuo PC!
